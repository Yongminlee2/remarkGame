## 자세한 설명 (최대 4000자)

```
AI와 1:1로 겨루는 한국어 끝말잇기입니다.
채팅하듯 말풍선을 주고받으며, 단어를 낼 때마다 그 뜻이 함께 뜹니다.


■ 43만 단어를 통째로 담았습니다

국립국어원 표준국어대사전을 바탕으로 429,961개 단어를 앱 안에 넣었습니다.
"이게 왜 안 되지?" 하는 일이 거의 없습니다.

단어를 낼 때마다 사전 뜻풀이가 말풍선 아래에 작게 뜹니다.
모든 단어에 뜻이 붙어 있어, 놀다 보면 몰랐던 낱말이 하나씩 남습니다.
동음이의어는 가장 널리 쓰이는 뜻을 골라 보여 줍니다.


■ 사전이 통째로 앱 안에 있습니다

사전도, 뜻풀이도, 그림도, 음악도 전부 내려받아 둔 상태입니다.
비행기 안에서도, 지하철에서도 그대로 됩니다.

게임 기록은 기기 안에만 저장되고, 앱을 지우면 함께 사라집니다.


■ 실력에 맞춰 고르세요

매우쉬움 / 쉬움 / 보통 / 어려움 네 단계입니다.
'매우쉬움'과 '쉬움'에서는 AI가 이어가기 좋은 단어만 골라 주고,
막다른 단어(한방단어)는 절대 쓰지 않습니다. 아이도 편하게 할 수 있습니다.

제한시간은 난이도와 따로 켜고 끕니다.
"제한시간 없이 느긋하게"를 켜면 시간에 쫓기지 않고 생각할 수 있습니다.

두음법칙도 챙깁니다. '이력'으로 끝나면 '역사'로 이어도 인정합니다.


■ 끝없이 이어지는 모험 모드

스테이지마다 다른 조건이 걸립니다.

- 두 글자만 / 세 글자만 / 네 글자만
- 세 글자 이상 / 네 글자 이상
- 받침으로 끝내기 / 받침 없이 끝내기
- 같은 글자로 계속 시작하기 (사과 → 사람 → 사탕)
- 앞 글자로 끝내기, 거꾸로 잇기 (사과 → 감사)

5스테이지마다 보스가 기다립니다.
세글자 도깨비, 받침 지킴이, 시간 도둑, 한방 마왕, 긴말 여왕,
거꾸로 대왕, 외곬 고집쟁이… 그리고 그 뒤로도 끝없이 이어집니다.

져도 스테이지가 뒤로 밀리지 않습니다. 편하게 도전하세요.


■ 모으는 재미

- 레벨 1~99, 브론즈부터 그랜드마스터까지
- 아바타 48종 도감 — 코인으로, 레벨로, 보스를 잡아서, 도전과제로 모읍니다
- 매일 바뀌는 미션 3개
- 연속 출석 보상

아이템도 있습니다.
시간 늘리기, 단어 힌트(세 개를 추천해 줍니다), AI 단어 바꾸기,
보상 2배, 그리고 지면 한 번 더 기회를 주는 부활.


■ 말로도 할 수 있습니다

마이크 버튼을 누르고 단어를 말하면 그대로 입력됩니다.
음성은 녹음하거나 저장하지 않습니다. 허용하지 않아도 키보드로 하면 됩니다.


■ 소리

효과음과 배경음악 20곡을 직접 만들어 넣었습니다.
곡마다 분위기가 달라 오래 해도 질리지 않습니다.


■ 이런 분께

- 출퇴근길에 가볍게 머리 쓸 거리를 찾는 분
- 아이와 함께 낱말 놀이를 하고 싶은 분
- 놀면서 낱말 뜻도 같이 익히고 싶은 분
- 데이터 안 쓰고 되는 게임이 필요한 분
```

| 질문 | 답 |
|---|---|
| 폭력 | 없음 |
| 성적 콘텐츠 | 없음 |
| 욕설 | 없음 |
| 통제 물질(술·담배·마약) | 없음 |
| 도박 / 도박 모사 | 없음 |

## 데이터 보안 양식 (Data safety)

| 질문 | 답 |
|---|---|
| 데이터를 수집하거나 공유합니까? | **아니요** |
| 데이터가 전송 중 암호화됩니까? | 해당 없음 (전송 자체가 없음) |
| 사용자가 데이터 삭제를 요청할 수 있습니까? | 앱을 삭제하면 모든 기록이 함께 지워짐 |

근거: 병합된 매니페스트의 권한은 `RECORD_AUDIO`, `VIBRATE` 둘뿐이고
`INTERNET` 권한이 없다. 네트워크로 나갈 방법 자체가 없다.

- `RECORD_AUDIO` — 음성으로 단어를 입력할 때만 쓴다. 안드로이드 음성 인식에 넘기고
  결과 문자열만 받는다. 녹음 파일을 만들지 않는다.
- `VIBRATE` — 정답·오답 진동.
