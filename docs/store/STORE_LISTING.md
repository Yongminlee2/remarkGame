## 데이터 보안 양식 (Data safety)

> ⚠️ **1.4.0(광고 포함)을 올릴 때 이 양식을 반드시 다시 제출해야 한다.**
> 1.3.11 까지의 답은 "수집 안 함" 이었고, 광고를 붙인 채 그대로 두면 **신고가 거짓이 되어
> 앱이 내려갈 수 있다.** 아래는 1.4.0 기준 답이다.

### 1.4.0 부터 (광고 있음)

| 질문 | 답 |
|---|---|
| 데이터를 수집하거나 공유합니까? | **예** |
| 데이터가 전송 중 암호화됩니까? | **예** |
| 사용자가 데이터 삭제를 요청할 수 있습니까? | 앱을 삭제하면 기기 안 기록이 함께 지워짐 |

수집·공유하는 데이터 유형 — **광고 SDK(구글 AdMob)가 가져가는 것**이다.
우리 코드가 직접 모으는 것은 여전히 없다.

| 유형 | 수집 | 공유 | 목적 | 필수 여부 |
|---|---|---|---|---|
| 기기 또는 기타 ID (광고 ID) | 예 | 예 | 광고 및 마케팅 | 필수 |
| 앱 활동 — 앱 내 상호작용 (광고 노출·클릭) | 예 | 예 | 광고 및 마케팅 | 필수 |
| 대략적인 위치 (IP 기반 국가·지역) | 예 | 예 | 광고 및 마케팅 | 필수 |

- **정확한 위치는 아니다.** GPS 권한이 없다.
- 게임 기록·코인·아바타는 기기 안에만 있고 나가지 않으므로 신고 대상이 아니다.
- 「앱 콘텐츠 → 광고」 선언도 **"예, 광고가 포함됩니다"** 로 바꿔야 한다.

병합 매니페스트 권한(1.4.0): `RECORD_AUDIO`, `VIBRATE`, `INTERNET`, `AD_ID`,
그리고 광고 SDK 가 스스로 넣는 `ACCESS_ADSERVICES_*`, `ACCESS_NETWORK_STATE`,
`FOREGROUND_SERVICE`, `WAKE_LOCK`.

### 1.3.11 까지 (광고 없음) — 기록용

| 질문 | 답 |
|---|---|
| 데이터를 수집하거나 공유합니까? | 아니요 |

근거였던 것: 권한이 `RECORD_AUDIO`, `VIBRATE` 둘뿐이고 `INTERNET` 이 없어
네트워크로 나갈 방법 자체가 없었다.

- `RECORD_AUDIO` — 음성으로 단어를 입력할 때만 쓴다. 안드로이드 음성 인식에 넘기고
  결과 문자열만 받는다. 녹음 파일을 만들지 않는다.
- `VIBRATE` — 정답·오답 진동.

## URL 갈아끼우기 — 콘솔에서 고칠 세 곳

방침 URL 칸은 **한 곳이 아니다.** 하나만 바꾸면 나머지가 옛 주소로 남아
나중에 경고가 뜬다. 순서대로 셋 다 확인할 것.

| # | 위치 | 칸 | 넣을 값 |
|---|---|---|---|
| 1 | 앱 콘텐츠 → 개인정보처리방침 | 개인정보처리방침 URL | `.../wordchain/privacy.html` |
| 2 | 앱 콘텐츠 → 데이터 보안 → 개요 | 개인정보처리방침 URL | 같은 주소 |
| 3 | 기본 스토어 등록정보 → 연락처 세부정보 | 웹사이트 | `.../wordchain/` |

- 1번과 2번은 **서로 다른 양식**이다. 2번은 데이터 보안 설문을 처음 화면부터
  끝까지 「다음」으로 넘겨 **제출**해야 저장된다. 중간에 나오면 안 바뀐다.
- 3번 웹사이트 칸은 선택 항목이라 비워도 되지만, 넣어 뒀다면 여기도 옛 주소다.
- 셋 다 고친 뒤 각 화면 오른쪽 위 **「변경사항 저장」**, 마지막에
  **「검토 후 게시」**(또는 개요 화면의 게시 버튼)까지 눌러야 실제로 반영된다.

## 나중에 광고를 넣을 때 함께 고쳐야 할 것

광고 SDK 는 인터넷을 쓰고 기기 식별자를 수집한다. 코드만 넣고 아래를 안 고치면
**정책 위반으로 앱이 내려간다.** 광고를 붙이는 커밋에서 한꺼번에 처리할 것.

| 대상 | 지금 상태 | 광고를 넣으면 |
|---|---|---|
| `AndroidManifest.xml` | INTERNET 권한 없음 | INTERNET 권한 추가 필요 |
| `docs/PRIVACY.md` | "인터넷 권한을 선언하지 않았습니다", "광고를 사용하지 않습니다" | 광고 제공자, 수집 항목, 광고 ID 사용을 명시해야 함 |
| 앱 정보 화면 (`AboutActivity`) | "인터넷 권한이 없어 … 광고와 분석 도구를 사용하지 않습니다" | 같은 이유로 수정 |
| 데이터 보안 양식 | "데이터를 수집하지 않음" | 광고 ID·기기 정보 수집으로 변경 |
| 콘텐츠 등급 설문 | 해당 없음 | 광고 포함 여부 문항에 '예' |
| **광고 ID 선언** (앱 콘텐츠 → 광고 ID) | **아니요** | '예' 로 바꾸고 매니페스트에 `com.google.android.gms.permission.AD_ID` 권한 추가 |
| 앱 콘텐츠 → 광고 | **아니요** | '예' 로 변경 |

> ⚠️ **광고 ID 선언과 매니페스트는 반드시 함께 바꾼다.**
> 선언만 '예' 로 두고 권한이 없으면 **출시 자체가 막힌다** — 실제로 첫 업로드 때
> 이것 때문에 거부됐다. 반대로 권한만 넣고 선언이 '아니요' 면 데이터 보안 신고와 어긋난다.
| 스토어 설명의 오프라인 문구 | "사전이 통째로 앱 안에", "데이터 안 쓰고" | 사전은 여전히 내장이지만 **완전 오프라인은 아니게 된다** — 문구 손볼 것 |

> 스토어 설명에서 광고 관련 표현은 이미 뺐다. 위 표는 그 외에 남은 것들이다.
